# IELTS Saitama Academy
Website edukasi Bahasa Inggris + IELTS 8.5.

## Fitur
- Pendaftaran sekali: nama lengkap, nama panggilan, tanggal lahir.
- Login berikutnya cukup memakai nama panggilan (disimpan lokal untuk demo).
- Sapaan Saitama.
- Link "LINK PEMBELAJARAN IELTS 8.5" ke Google Drive pengguna.
- Level MEDIUM, HARD, DARKNES.
- Quiz wajib benar seluruhnya untuk membuka level berikutnya.
- XP dan rank Bronze, Steel, Gold, Obsidian.
- Check-in harian.
- Mini AI-style Saitama Q&A.
- Tampilan futuristik responsive.

## Catatan penting untuk produksi
Versi ini adalah demo frontend yang bisa langsung dibuka. Data pengguna tersimpan di browser (localStorage), bukan database online.
Notifikasi otomatis jam 09.00 dan 19.00 serta sinkronisasi database/Google Drive membutuhkan backend + service worker/push notification + database/API.
